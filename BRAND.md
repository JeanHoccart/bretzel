# Bretzel brand

## Idea

The mark is a literal **pretzel knot** reduced to one warm, recognisable shape.
Its three openings echo typed state, server rendering and the browser loop,
without turning the identity into a technical diagram.

## Positioning

**Category:** Server-Driven UI framework for Python.

**Promise:** Build reactive web applications without maintaining two
application models.

**Primary line:** Typed Python in. Reactive web apps out.

**Descriptor:** Server-Driven UI for Python — typed state, zero npm, batteries
included.

## Colours

| Token | Hex | Role |
|---|---:|---|
| Bretzel Plum | `#682747` | Primary mark, links and key actions |
| Raspberry | `#A63F6B` | Active and expressive accent |
| Warm Dough | `#E99536` | Mark and human highlight, never body text |
| Cream | `#FFF8F0` | Warm light background |
| Ink | `#201820` | Primary text and dark surfaces |
| Mist | `#EEE7EC` | Borders and quiet surfaces |

Plum on Cream is the default high-contrast pairing. Warm Dough is an accent,
not a substitute for readable foreground text.

## Typography

- Product and prose: **Inter**, with `system-ui` as the no-download fallback.
- Code: **IBM Plex Mono**, with `ui-monospace` as the fallback.
- Wordmark: lowercase `bretzel`, semibold, slightly tightened.

The website may self-host fonts later. Documentation must remain usable with
the system fallbacks and without third-party requests.

## Voice

Direct, exact and quietly playful. Show the mechanism in code. Avoid claiming
that Bretzel replaces every web framework, and avoid food puns as a substitute
for an explanation.

## Mark usage

- Keep clear space equal to the central opening around the mark.
- Do not rotate, outline or place the full-colour mark on a busy background.
- Use the monochrome asset at small sizes or where colour is unavailable.
- The 64×64 mark is the source for favicons and avatars.
