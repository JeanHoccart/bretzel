# Les parametres typables `str` qu'une SENTINELLE de chaine ne traverse
# pas — etat FIGE au 2026-08-19, 35 sur 430 candidats.
#
# Ce ne sont pas des defauts : un parametre qu'une string ne peut pas
# traverser (une enumeration, un `int` annote `Any`, un couple
# d'arguments requis) n'est pas un slot textuel. Il sort de la
# population par DEFINITION.
#
# Mais « par definition » etait une AFFIRMATION du commentaire, jamais
# verifiee : un composant qui cesse de se construire tombait dans la
# meme branche et passait pour un refus de principe. La table nomme les
# 35, donc le 36e se voit.
#
