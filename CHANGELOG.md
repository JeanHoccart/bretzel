# Changelog

Bretzel n'a **pas encore été publié**. Le premier candidat est `0.1.0a1` et rien
n'a été livré à des utilisateurs, donc il n'y a aucune version à consigner
ici : ce fichier commencera à la première release publique, au format
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) et en
[SemVer](https://semver.org/spec/v2.0.0.html).

En attendant, l'historique **est** `git log` — les messages de commit
portent le pourquoi, pas seulement le quoi. Pour le récit d'ensemble
(itérations V1 → V2 → V3 et décisions structurantes), lire `EVOLUTION.md`.

> Ce fichier est resté figé de mai 2026 au 2026-08-01 sur une entrée
> « Phase 0 — pas encore de code applicatif », alors que le framework
> comptait 76 composants publics. Un changelog qui ment sur l'existence
> même du code est pire qu'un changelog absent.
